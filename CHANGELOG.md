# Changelog

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/). Каждая сборка `main` публикуется как `vX.Y.Z.N`; здесь перечислены изменения базовой версии `X.Y.Z`.

## [1.1.0] — 2026-11-13

### Добавлено
- Английский интерфейс: язык браузера по умолчанию, ручной выбор в шапке popup. `_locales` для названия и описания расширения.
- Срок действия в списке («через 3 дн.», точная дата в подсказке), сортировка по сроку, поле даты и времени в редакторе.
- Поиск по значению и фильтр по флагам: Secure, HttpOnly, session, постоянные, partitioned.
- Копирование значения из строки списка.
- Декодированный вид значения: URL, Base64/Base64url, JWT (только просмотр).
- «Дублировать» в редакторе.
- Отмена последнего удаления и необязательная резервная копия перед удалением.
- Прогресс и остановка импорта.
- Горячая клавиша `Alt+Shift+K`.
- Отчёт покрытия с порогами, Prettier, ESLint для `scripts/`, CodeQL, Dependabot, закрепление Actions по SHA.
- `ROADMAP.md`, `CONTRIBUTING.md`, `SECURITY.md`, шаблоны issue.

### Изменено
- Кнопки popup на русском: «Импорт», «Экспорт», «Добавить», «Удалить», «Сохранить», «Отмена».
- Импорт проверяет конфликты и результат записи точечным запросом к Chrome вместо перечитывания всех cookies сайта на каждую запись.
- `tldts` перенесён в `dependencies`: он входит в сборку расширения.

### Исправлено
- Срок больше 400 дней в редакторе: Chrome сокращал его после записи, а Cookiess сообщал об ошибке, хотя запись уже была сделана. Теперь срок сокращается до записи, и это видно заранее.
- Ошибки импорта сохраняют точную причину для каждой записи.
- Массовое удаление перечисляет все ошибки, а не только первую.
- Переход вкладки на сайт без выданного доступа теперь обнаруживается; сообщение о недоступном адресе вкладки стало точным.
- Уязвимости dev-зависимостей (vite, vitest, minimatch): `npm audit` — 0.

## [1.0.2]

Первая публичная линейка сборок: просмотр, редактирование, импорт и экспорт cookies текущего сайта; три формата файлов; браузерные проверки настоящего popup в CI.
