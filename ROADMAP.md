# Cookiess roadmap

Версия 1.1.0. Статусы: `[x]` сделано · `[ ]` запланировано · `[~]` требует внешнего действия или отдельного решения.

## 1. Ошибки и надёжность

- [x] Редактор сокращает срок больше 400 дней так же, как импорт, и предупреждает об этом до сохранения (раньше Chrome записывал урезанный срок, а Cookiess сообщал об ошибке).
- [x] Импорт сохраняет точную причину отказа каждой записи вместо общего «Chrome отклонил запись».
- [x] Массовое удаление показывает все ошибки, а не только первую.
- [x] Импорт и запись без O(n²): точечный `cookies.getAll` по name/domain/path вместо перечитывания всего сайта на каждую запись.
- [x] Прогресс и остановка длинного импорта.
- [x] Смена сайта во вкладке без доступа к новому сайту обнаруживается (без `change.url`), а сообщение об истёкшем доступе к вкладке стало точным.
- [x] Удалён дублирующий `storageIdentity()`.

## 2. Функции

- [x] Понятный срок действия: дата и время в редакторе (синхронно с Unix seconds) и «истекает через …» в списке.
- [x] Копирование значения одной cookie из строки списка.
- [x] Поиск по значению и фильтр по флагам (Secure, HttpOnly, session, постоянные, partitioned).
- [x] Декодирование значения в редакторе: URL, Base64/Base64url, JWT (только просмотр).
- [x] Резервная копия перед массовым удалением и отмена последнего удаления.
- [x] Дублирование cookie из редактора.
- [x] Горячая клавиша открытия popup (`Alt+Shift+K`, меняется в `chrome://extensions/shortcuts`).
- [~] Side panel / панель DevTools, чтобы черновик не терялся при закрытии popup. Требует другой модели доступа: `activeTab` не выдаёт URL вкладки боковой панели, нужны `tabs` или постоянные host permissions. Решение о расширении разрешений — за владельцем проекта.

## 3. Интерфейс и локализация

- [x] Все кнопки на русском (Импорт, Экспорт, Добавить, Удалить, Сохранить, Отмена).
- [x] `_locales/` (ru по умолчанию, en) для названия и описания в манифесте и магазине.
- [x] Полный английский перевод popup: словари `src/locales/`, язык браузера по `chrome.i18n.getUILanguage()` или ручной выбор.
- [ ] Браузерный прогон английского интерфейса (сейчас строки проверены юнит-тестами).
- [~] Проверка со скринридером (NVDA/VoiceOver) — нужен ручной прогон человеком.

## 4. Инфраструктура и качество

- [x] `npm audit fix` (dev-зависимости: vite, vitest, minimatch).
- [x] Dependabot для npm и GitHub Actions.
- [x] GitHub Actions закреплены по SHA; CodeQL.
- [x] Отчёт о покрытии (`npm run test:coverage`).
- [x] Чистая логика popup (фильтр, сортировка, сроки, декодирование) вынесена из `src/main.ts` в тестируемые модули (`src/view.ts`, `src/decode.ts`).
- [ ] Дальнейшее разделение `src/main.ts` по экранам (список, редактор, импорт, экспорт) с DOM-тестами.
- [x] `engines` в `package.json`.
- [x] Prettier и проверка форматирования в CI.
- [x] ESLint проверяет `scripts/`.
- [x] `CHANGELOG.md`, `CONTRIBUTING.md`, `SECURITY.md`, шаблоны issue.
- [~] Включить Private vulnerability reporting в настройках репозитория (на него ссылается `SECURITY.md`) — действие владельца.
- [x] Документация синхронизирована с текущими числами тестов и версией.
- [ ] TypeScript 7: ждём поддержки в `typescript-eslint` (8.72 поддерживает TypeScript до 6.1). Мажорные версии TypeScript в Dependabot отключены до тех пор.
- [ ] Vite 8: его минификатор Oxc удваивает бандл popup (186 → 326 КБ) из-за данных `tldts`. Остаёмся на Vite 7, пока это не исправят или пока не найдётся настройка; Dependabot для мажорных версий Vite отключён.
- [~] Браузерный тест popup на macOS в CI — сначала прогнать вручную, затем включить как обязательную проверку релиза.
- [~] Публикация в Chrome Web Store (автообновления) — нужен аккаунт разработчика и явное разрешение владельца.
