# Cookiess visual direction

A compact data instrument: warm paper (#f5f4ef), charcoal ink (#252d28), moss accent (#476a48). Dark theme uses deep olive charcoal and muted sage. No gradients or remote assets.

460px wide, maximum 590px high. Brand bar with geometric cookie mark and theme selector; host header; search and sort; sticky selection count; independently scrolling dense 62px rows; fixed four-action footer. Rounded controls with restrained borders, strong keyboard focus. System sans for Russian text, local system monospace for cookie identities and values. Rows separate identity from value; flags use small neutral labels.

Editor and import/export replace the list area while retaining context and footer. Forms are scrollable. Inline validation, accessible status messages, clear permission/empty/error states. Dirty drafts require confirmation before internal navigation. Themes follow system by default and save locally. SVG line action icons and generated original PNG extension icons. Reduced motion supported.
